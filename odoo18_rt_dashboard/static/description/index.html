Vista del dashboard

Accede desde el menú principal RT Dashboard. El sistema crea automáticamente un dashboard por departamento. Las tarjetas KPI muestran el valor actual, la variación respecto al período anterior y un minigráfico histórico.

Vista principal del dashboard — tarjetas KPI con indicador de estado, gráfico de barras por agrupación y gráfico de área histórico. Actualización automática sin recargar.

💡 Indicador LIVE: El badge ⚡ LIVE en la cabecera confirma que la conexión bus.bus está activa. Los datos se actualizan cada vez que el cron evalúa un KPI (por defecto cada 60 segundos).

Formulario de definición de KPI — campos de identidad, fuente de datos, umbrales y valores en caché.

Tokens de fecha en el dominio

Puedes usar tokens dinámicos en el campo Domain para filtros relativos a hoy:

TokenSe reemplaza por
{hoy}Fecha de hoy (YYYY-MM-DD)
{inicio_mes}Primer día del mes actual
{inicio_año}Primer día del año actual
{hace_30d}Hace 30 días
{hace_90d}Hace 90 días
{hace_365d}Hace 365 días

Ejemplo — facturas del mes actual:

[["invoice_date",">=","{inicio_mes}"],["invoice_date","<=","{hoy}"],["state","=","posted"]]

KPIs de Fórmula

Los KPIs de tipo Fórmula combinan el resultado de otros KPIs mediante expresiones aritméticas. Permiten calcular ratios, runway financiero, márgenes, etc.

KPI de fórmula — la expresión referencia el nombre técnico de otros KPIs entre llaves. El resultado se evalúa en tiempo real.

💡 Nombres técnicos: El campo Name (técnico) del KPI referenciado debe coincidir exactamente con el token en la fórmula. Usa nombres simples sin espacios: saldo_57, burn_rate, ventas_mes.

Selector de iconos y personalización visual

Selector visual de iconos con emojis agrupados por categoría. Haz clic en el icono del campo para abrir el panel.

Reglas de alerta

Menú → RT Dashboard → Alert Rules

Cada regla monitoriza un KPI y dispara notificaciones cuando supera (o cae por debajo de) un umbral. Cooldown configurable para evitar spam.

Configuración de regla de alerta — KPI + nivel (warning/crítico) + canales + mensaje con token {value}.

CanalRequisito
Dashboard (in-app)Ninguno. Banner automático en todos los dashboards abiertos.
WhatsAppToken de WhatsApp Business API + número de teléfono destino.
TelegramToken del bot de Telegram + chat_id del receptor.

Inteligencia Artificial (Anthropic Claude)

📋 Briefing ejecutivo diario

El cron diario genera un resumen en lenguaje natural con los KPIs más relevantes de cada departamento, destacando anomalías y tendencias. Se almacena en Dashboard RT → AI Briefings y se envía por los canales configurados.

Requiere clave API de Anthropic Claude (la clave empieza por sk-ant-). Obtén una en console.anthropic.com y configúrala en Ajustes → Técnico → Parámetros del sistema:
ClaveValor
rt_dashboard.llm_api_keyTu clave sk-ant-...
rt_dashboard.llm_modelclaude-sonnet-4-20250514 (opcional)
Activa el modo desarrollador con ?debug=1 si no ves el menú Técnico.

🤖 Generador de KPIs por IA

Menú → Crear KPI con IA. Describe en texto libre el KPI que necesitas, por ejemplo:

"ventas del mes pasado en euros,
agrupadas por vendedor,
solo facturas confirmadas"

Claude configura automáticamente el modelo, función de agregación, campo y dominio, listos para revisar y guardar. Requiere la misma clave API de Anthropic.

🔍 Detección de anomalías

El motor de anomalías analiza las series históricas de cada KPI y notifica si un valor se desvía significativamente de la media histórica. La sensibilidad se configura por KPI.

Instalación y actualización

Instalación inicial

1
Copia la carpeta odoo_rt_dashboard en tu directorio de addons personalizados.
2
Reinicia el servidor Odoo y ve a Ajustes → Técnico → Actualizar lista de módulos.
3
Instala RT Dashboard desde la lista de aplicaciones.
4
El módulo crea automáticamente KPIs predefinidos para 7 departamentos y un dashboard por departamento asignado al administrador.

Actualización

./odoo-bin -u odoo_rt_dashboard -d <base_de_datos> --stop-after-init
⚠ Tras actualizar con cambios de JavaScript: ve a Ajustes → Técnico → Ir a URL y añade ?debug=assets a la URL del dashboard, o limpia la caché del navegador con Ctrl+Shift+R.

Preguntas frecuentes

¿Por qué un KPI muestra 0?

  • El nombre técnico de un KPI referenciado en una fórmula no coincide exactamente con el token {nombre}.
  • El dominio filtra demasiado — prueba con [] para ver si hay datos.
  • El campo elegido es calculado y no agregable por SQL. Usa Compute Now y revisa los logs del servidor.
  • El campo no existe en el modelo. Usa el Field Selector para confirmar.

¿Cómo cambiar un KPI de departamento?

Edita el KPI y cambia el campo Departamento. El módulo lo quita automáticamente del dashboard anterior y lo añade al nuevo.

¿Cómo crear dashboards personalizados por usuario?

Ve a Ajustes → Técnico → RT Dashboard y crea un registro con el usuario y los KPIs deseados. El dashboard aparecerá como una pestaña adicional para ese usuario.

¿El indicador LIVE desaparece?

La conexión bus.bus se pierde si el servidor Odoo reinicia. Recarga la página para reconectar.

¿Qué clave API necesito para la IA?

El módulo usa Anthropic Claude. Obtén tu clave en console.anthropic.com. La clave empieza por sk-ant-. No uses claves de OpenAI (empiezan por sk-).

¿Cómo configuro las alertas de WhatsApp?

Necesitas una cuenta de WhatsApp Business API (Meta). Introduce el token en la regla de alerta junto con el número de teléfono destino en formato internacional (+34600123456).

¿Cómo configuro las alertas de Telegram?

Crea un bot con @BotFather en Telegram y obtén el token. El chat_id es el ID numérico del chat o grupo al que debe enviar el mensaje.
