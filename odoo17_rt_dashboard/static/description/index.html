Dashboard View

Access from the main menu RT Dashboard. The system automatically creates one dashboard per department. KPI cards show the current value, variation vs the previous period, and a historical mini-chart.

Main dashboard view — KPI cards with status indicator, bar chart by grouping and historical area chart. Automatic updates without page reload.

💡 LIVE indicator: The ⚡ LIVE badge in the header confirms that the bus.bus connection is active. Data updates every time the cron evaluates a KPI (default every 60 seconds).

Date tokens in domain

You can use dynamic tokens in the Domain field for filters relative to today:

TokenReplaced by
{today}Today's date (YYYY-MM-DD)
{month_start}First day of current month
{year_start}First day of current year
{last_30d}30 days ago
{last_90d}90 days ago
{last_365d}365 days ago

Example — invoices from current month:

[["invoice_date",">=","{month_start}"],["invoice_date","<=","{today}"],["state","=","posted"]]

Formula KPIs

Formula KPIs combine the result of other KPIs using arithmetic expressions. They allow calculating ratios, financial runway, margins, etc.

Formula KPI — the expression references the technical name of other KPIs in curly braces. The result is evaluated in real time.

💡 Technical names: The Technical name field of the referenced KPI must match exactly the token in the formula. Use simple names without spaces: balance_57, burn_rate, monthly_sales.

Alert Rules

Menu → RT Dashboard → Alert Rules

Each rule monitors a KPI and triggers notifications when it exceeds (or falls below) a threshold. Configurable cooldown to avoid notification spam.

Alert rule configuration — KPI + level (warning/critical) + channels + message with {value} token.

ChannelRequirement
Dashboard (in-app)None. Automatic banner on all open dashboards.
WhatsAppWhatsApp Business API token + destination phone number.
TelegramTelegram bot token + chat_id of the recipient.

Artificial Intelligence (Anthropic Claude)

📋 Daily Executive Briefing

The daily cron generates a natural language summary with the most relevant KPIs for each department, highlighting anomalies and trends. Stored in RT Dashboard → AI Briefings and sent via configured channels.

Requires an Anthropic Claude API key (starts with sk-ant-). Get one at console.anthropic.com and configure it in Settings → Technical → System Parameters:
KeyValue
rt_dashboard.llm_api_keyYour sk-ant-... key
rt_dashboard.llm_modelclaude-sonnet-4-20250514 (optional)
Enable developer mode with ?debug=1 if the Technical menu is not visible.

🤖 AI KPI Generator

Menu → Create KPI with AI. Describe in plain text the KPI you need, for example:

"last month's sales in euros,
grouped by salesperson,
confirmed invoices only"

Claude automatically configures the model, aggregation function, field and domain — ready to review and save. Requires the same Anthropic API key.

🔍 Anomaly Detection

The anomaly engine analyzes the historical series of each KPI and notifies when a value deviates significantly from the historical average. Sensitivity is configurable per KPI.

Installation & Update

Initial Installation

1
Copy the odoo_rt_dashboard folder into your custom addons directory.
2
Restart the Odoo server and go to Settings → Technical → Update Module List.
3
Install RT Dashboard from the apps list.
4
The module automatically creates predefined KPIs for 7 departments and one dashboard per department assigned to the administrator.

Update

./odoo-bin -u odoo_rt_dashboard -d <database> --stop-after-init
⚠ After updating with JavaScript changes: go to Settings → Technical → Go to URL and add ?debug=assets to the dashboard URL, or clear the browser cache with Ctrl+Shift+R.

Frequently Asked Questions

Why does a KPI show 0?

  • The technical name of a KPI referenced in a formula does not match exactly the {name} token.
  • The domain filters too much — try [] to see if there is data.
  • The chosen field is computed and not SQL-aggregable. Use Compute Now and check the server logs.
  • The field does not exist in the model. Use the Field Selector to confirm.

How do I move a KPI to another department?

Edit the KPI and change the Department field. The module automatically removes it from the previous dashboard and adds it to the new one.

How do I create custom dashboards per user?

Go to Settings → Technical → RT Dashboard and create a record with the user and desired KPIs. The dashboard will appear as an additional tab for that user.

The LIVE indicator disappears?

The bus.bus connection is lost if the Odoo server restarts. Reload the page to reconnect.

What API key do I need for AI?

The module uses Anthropic Claude. Get your key at console.anthropic.com. The key starts with sk-ant-. Do not use OpenAI keys (they start with sk-).

How do I configure WhatsApp alerts?

You need a WhatsApp Business API account (Meta). Enter the token in the alert rule along with the destination phone number in international format (+34600123456).

How do I configure Telegram alerts?

Create a bot with @BotFather on Telegram and get the token. The chat_id is the numeric ID of the chat or group to which the message should be sent.
